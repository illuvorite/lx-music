# 设计规范（QQ 音乐风格复刻）

> 目的：为「整体视觉与交互对齐 QQ 音乐桌面端」提供唯一的取值依据。
> 所有页面改造必须只引用本文件的 token，不允许再出现零散硬编码颜色/尺寸。
> 品牌约定：**界面内不出现任何第三方商标、LOGO、官方文案**，图标全部自绘 SVG，文案使用中性通用词。

## 3. 页面骨架

```
窗口 1080×676（可缩放，最小 1000×670）
├─ 外壳 #F0F0F0，边距 11px（顶/右/下）
├─ 左侧栏 214px（通高，位于播放栏之上）
│   ├─ 用户行（头像 26 + 昵称 + 会员标识 + 展开箭头）24px 起
│   ├─ 快捷入口 2 格 86×48（选中 #D7D7D7，常态 #E8E8E8）
│   ├─ 新建入口（虚线 180×27）
│   ├─ 一级导航（5 行，行距 48，图标 18 + 文本 13 + 计数）
│   ├─ 分组标题（12px 粗体 + 右侧操作）
│   ├─ 歌单列表（行 40，封面 27）
│   └─ 底部图标行（4 个 30×30，间距 7）
├─ 主面板 #F5F5F5、圆角 10、右/下留 11px
│   ├─ 工具栏 48px（导航钮 3 + 搜索 227×31 + 功能入口 2 + 窗口钮 4）
│   └─ 内容区（滚动，滚动条 4px #D3D3D3）
└─ 播放栏 72px 通栏（最底部贴边）
```

内容区网格：`repeat(auto-fill, minmax(150px, 1fr))`，列数随窗口 5→8 列，间距 `24px`。

## 5. 交互与动效

- 过渡：`cubic-bezier(0.16, 1, 0.3, 1)`；时长 150ms（颜色）/ 200ms（位移）/ 280ms（面板）。
- hover 只做「底色/颜色/轻微位移（≤2px）/阴影」；禁止缩放超过 1.03 以免抖动。
- 键盘：`↑/↓` 移动选中行、`Enter` 播放、`Space` 播放/暂停、`Esc` 关闭浮层、`Ctrl/Cmd+F` 聚焦搜索。
- 列表超过 500 行启用虚拟滚动；滚动条统一 4px `#D3D3D3`。
- 加载中不阻塞滚动；网络失败给行内重试；所有异步操作必须有失败提示（Toast）。
- 提示文案统一：`已添加到「xxx」`、`播放失败，已尝试切换音源`、`暂无搜索结果`。

---

## 6. 深色与主题

- 本轮**只做浅色**：所有 token 取本文件固定值，不再跟随主题主色派生。
- 其余主题在设置页仍可选，但应用外壳与卡片使用 `--qm-*`，保持浅色观感一致（后续如需深色，只需补一份 `--qm-*` 深色映射）。
